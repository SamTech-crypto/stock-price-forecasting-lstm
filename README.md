# 📈 Stock Price Forecasting with LSTM + ARIMA

This project uses both ARIMA and LSTM models to forecast stock prices based on historical financial data. It includes an interactive dashboard built with Dash and Plotly, with support for web app deployment and hyperparameter tuning.

---

## 🚀 Features

- ✅ ARIMA model for trend analysis
- ✅ LSTM neural network for sequence prediction
- ✅ SMOTE oversampling for class imbalance
- ✅ Hyperparameter tuning (batch size, epochs, etc.)
- ✅ Dash web app with interactive Plotly charts
- ✅ Ready-to-deploy (Heroku, AWS, etc.)
